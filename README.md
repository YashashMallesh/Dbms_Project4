Disaster Management is the Full Stack Django Application .
The application stores the details of the disasters and only displays the list of disasters in the homepage.
# Installing packages:
- Django
 ```powershell
 pip install django
 ```
- Creating project
```powershell
django-admin startproject myproject
```
- Databases
```powershell
pip install psycopg2
 ```
```powershell
pip install Pillow
 ```
- Migrations
```powershell
py manage.py makemigrations
 ```
```powershell
py manage.py migrate
 ```
- Run Server
```powershell
py manage.py runserver
```
